# Eclipse Café ☕  

A database-driven Café Management Web Application developed to simulate a real-world ordering system using PHP and MySQL.

---

## 📌 Project Description

Eclipse Café is a web-based application that allows users to browse café menu items dynamically and place orders through an interactive interface.  

The system is fully connected to a structured MySQL database, ensuring proper data storage, retrieval, and management.  

This project focuses on backend development, relational database design, and frontend-backend integration.

---

## ✨ Core Features

- Dynamic menu display retrieved from database  
- Order placement and storage functionality  
- Structured relational database schema  
- Admin account logic implementation  
- Sample data for realistic testing  

---

## 🛠 Technology Stack

- **PHP** – Backend development  
- **MySQL** – Database management  
- **HTML** – Structure  
- **CSS** – Styling  
- **JavaScript** – Basic interactivity  

---

## ⚙️ Installation & Setup

1. Clone the repository  
2. Import the SQL file into MySQL  
3. Configure database connection in PHP files  
4. Run using XAMPP or any local server environment

## 🎯 Concepts Applied

- Backend data handling
